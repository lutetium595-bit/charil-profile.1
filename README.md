# 챠릴 프로필 웹사이트 (완성형)

하늘색·파란색 메인 테마와 노란색 포인트의 반응형 프로필 웹사이트입니다. 메인에는 프로필 사진, 비워진 프로필 정보, 주간 일정만 표시합니다. 상단 메뉴에는 일정표, 공지사항, 의상목록, 업보목록이 있습니다.

## 포함된 기능

- **관리자 로그인:** 우상단 톱니바퀴 버튼 → 비밀번호 입력. 비밀번호는 서버 환경변수에만 저장됩니다.
- **프로필 편집:** 로그인 후 톱니바퀴 → 프로필 수정. 각 항목과 사진을 변경할 수 있습니다.
- **주간 일정:** 이전/다음 주 이동. 일정표 메뉴에서 로그인한 관리자가 날짜별로 일정 추가·수정·삭제.
- **공지사항·의상목록·업보목록:** 관리자만 항목 추가·수정·삭제, 일반 방문자는 보기만 가능. 의상/업보에 사진 등록 가능.
- **데이터 저장:** PostgreSQL에 저장. 다른 방문자도 같은 데이터를 확인할 수 있습니다.
- **반응형:** 모바일/PC 지원.

## GitHub + Render 배포

1. 새 GitHub 저장소를 만들고 이 폴더의 파일들을 그대로 업로드합니다. `public` 폴더 구조를 유지하세요.
2. Render에서 **Postgres** 데이터베이스를 생성합니다. 데이터베이스 URL을 준비합니다.
3. Render에서 **New → Web Service**를 생성하고 해당 GitHub 저장소를 연결합니다.
4. 설정: **Runtime = Node**, **Build Command = `npm install`**, **Start Command = `npm start`**.
5. Render Web Service의 **Environment**에 다음 값을 등록합니다.
   - `DATABASE_URL` = Render PostgreSQL의 **Internal Database URL** (같은 계정/리전에서 연결 가능한 경우)
   - `ADMIN_PASSWORD` = 12자 이상의 강력한 관리자 비밀번호
   - `SESSION_SECRET` = 24자 이상의 별도 무작위 문자열
   - `NODE_ENV` = `production`
   - `DB_SSL` = `false` (Render 내부 DB 연결 시 일반적인 설정; 외부 제공업체의 SSL 요구 시 `true`)
6. 배포 완료 후 사이트에 접속합니다. 최초 프로필 정보와 일정은 비어 있습니다. 샘플 프로필 이미지는 직접 변경할 수 있습니다.
7. 오른쪽 위 **⚙** → 관리자 로그인 → 프로필 정보 수정. 일정은 **일정표** 메뉴에서 날짜별로 등록하세요.

## 유의 사항

- `.env` 파일이나 실제 비밀번호는 GitHub에 올리지 마세요. `.env.example`은 예시입니다.
- 이미지 파일은 업로드 후 PostgreSQL에 저장되는 구조입니다. 이미지 한 장당 2.4MB 이하를 권장합니다. 대량 이미지 운영 시 객체 스토리지로 전환하는 편이 좋습니다.
- 서버 재시작/재배포 시 로그인 세션은 초기화되므로 다시 로그인해야 합니다. 등록된 프로필과 일정/게시물은 PostgreSQL에 남습니다.
- 데이터베이스는 배포와 별개입니다. 중요한 데이터를 운영하기 전에는 Render의 백업/복구 정책을 확인하세요.
- 주간 일정은 기본값을 임의로 채우지 않았습니다. 관리자가 입력한 일정만 표시합니다.
- 시안의 이미지와 완전히 동일한 픽셀 단위 재현은 아니며, 레이아웃/색상/장식과 프로필 사진을 바탕으로 실제 조작 가능한 UI로 구현했습니다.
- 본 프로젝트는 새 독립 사이트입니다. 기존 다른 사이트의 데이터베이스에 연결하지 마세요.

## 로컬 실행

Node.js 20+ 및 PostgreSQL 필요. `.env.example`을 참고해 환경변수를 설정한 다음 `npm install && npm start`로 실행하세요. 서버는 `http://localhost:3000`에서 열립니다.
